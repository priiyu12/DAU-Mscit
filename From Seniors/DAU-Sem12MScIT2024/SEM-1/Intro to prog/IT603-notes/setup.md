
TeachingAid - A WebApp for polling
TechStack - MERN Stack

M - MongoDB
E - Express
R - React
N - Node.js

In order to setup this project 

Make sure node and react are installed on your systems.
Step 1 : Get the project from GitHub (https://github.com/gamekeepers/teaching-aid.git) in a directory
Step 2 :  You will find a folder structure like this 
![[Pasted image 20241220113803.png]]
Go inside the directory in the command prompt (For eg : TeachingAid is name of my directory)
![[Pasted image 20241220113915.png]]

Step 3 : Write a statement to install all the required packages
`npm i` 
(This will download all the packages and modules which are required for the project)

The code for Backend is in 'server' Directory and code for Frontend is in 'client directory'

Step 4 : To Run the Backend code go in the server directory with
`cd server`
![[Pasted image 20241220114834.png]]

Then write the command to run the backend code `npm start`

Step 5 : To Run the Frontend code go in the client directory with
`cd client`
![[Pasted image 20241220115125.png]]
Then write the command to run the frontend code `npm start`

Backend Port : 8080
Frontend Port : 3000
